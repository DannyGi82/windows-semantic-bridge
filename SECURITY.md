# Security Policy

Experimental developer preview. Do not expose the MCP tools, local IPC or browser host to untrusted clients. Accessible UI text can contain private data. Avoid connecting to sensitive applications. This software is not a sandbox or security boundary against malicious processes on the same user account.

Please report security vulnerabilities privately to the maintainer before sharing technical exploit details. Never post private screenshots, auth/session tokens, credentials or browser profiles in an issue.
